Moves by hand in M1 · ALLOWED_MOVES
Inbox→Research, Ready* Research→Ready* any active→Parked Parked→Inbox, Research, Ready*, Archived Shipped→Archived
* needs a brief with a goal. Other moves are system only (runs, checks, ship).
A move to the stage the task is already in does nothing, makes no event, and says so. --reason is saved in the task.stage_changed event.
Moves that the system makes (Ready → Running and more) are already in the table, tagged system. M2, M4 and M5 turn them on.
