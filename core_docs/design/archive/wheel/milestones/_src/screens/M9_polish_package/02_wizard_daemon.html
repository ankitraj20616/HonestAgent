Welcome. First, the background service.

Saarthi does its work in a small background program called saarthid. The app and the saarthi CLI both talk to it. It starts by itself when you log in.

Install the daemon

Run in a terminal. No sudo needed.
1
Install saarthi with uv and start the service. Installs uv too, if it is missing.
$curl -fsSL https://github.com/ankit/saarthi/releases/download/v1.0.0/install.sh | bash
2
Already have saarthi on PATH? Only add the service:
$saarthi daemon install-service
