Every stdout line is saved byte for byte, in order. A line that is not JSON prints as RAW and is still kept (rule 4). M2's FakeAdapter replays these files.
Without --record the script only prints, so a bad run never overwrites a good fixture. Paths are cleaned to <WORKDIR> and <HOME> before saving.
The .meta.json sidecar holds argv, stdin, agent version, exit code and an expect block (for example needs_input: true) for M2 mapping tests.
