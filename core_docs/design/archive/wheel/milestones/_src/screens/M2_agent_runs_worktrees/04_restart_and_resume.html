Daemon dies, nothing is lost

Every event is on disk as it comes. On start, the daemon cleans up and marks what it could not finish, so you can pick it up.

On daemon start
Run was live
interrupted, checkpoint, task Failed
Run ended with a question
unchanged, still needs_input
Run was queued
back in the queue, same order
Clean daemon stop
stop live runs, checkpoint, interrupted
Before a resume, leftover agent processes are killed, but only when the pid's folder is the task worktree and its command is the agent. pgrep finds nothing.
Resume continues the same run: same ID, same log, same agent session. Tokens and cost add up. A run with no session ID cannot resume; the CLI says "start a new run".
Every run end saves a hidden checkpoint under refs/saarthi/checkpoints/. The task branch and its history do not change.
