Goal
Users can reset a forgotten password by email. Today they must email support and wait (ticket #4821).
Acceptance criteria
POST /auth/password-reset sends an email with a single-use link
The link expires after 30 minutes
A used or expired token returns 410
Unknown email still returns 202 (no user enumeration)
Tests cover all of the above
Notes
Use the existing mailer. No new infra (no Redis). Follow OWASP guidance.
