M10 · saarthi CLI

Jira tickets from the terminal

The same daemon API as the Tickets page. Log in once per site, list tickets, start a task from one, and OK each write back.

The token prompt never echoes. The token goes to a file only you can read, never into the repo, logs or events.
A pending action waits for ticket send or ticket skip. With auto_send = true it is sent at once.
Commands
saarthi jira login | statusconnect a site, show who you are saarthi tickets list [--view] [--jql]Mine, Sprint or a saved view; --refresh, --json saarthi tickets show | start KEYread one ticket, or make a task from it saarthi task edit T-0012 --ticket ACME-142link a task you already have saarthi ticket actions | send | skipwrite back to Jira, with your OK
Token wrong or expired? Commands stop with 401 and print the fix: saarthi jira login.
